# 📸 Photos et logo

1. Dans le dépôt GitHub, crée un dossier `images` si besoin.
2. Envoie tes photos dans ce dossier.
3. Dans `config.js`, indique le chemin.

Exemple :
```js
images: {
  logo: "images/logo.png",
  accueil: "images/accueil.jpg",
  region: "images/calanques.jpg",
  gallery: [
    "images/piscine.jpg",
    "images/restaurant.jpg",
    "images/mobilhome.jpg"
  ]
},
```

Tu peux utiliser JPG, JPEG, PNG ou WEBP.

Pour l'instant, le reste du contenu continue à être modifié dans `config.js`.
