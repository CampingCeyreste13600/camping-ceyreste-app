# V9 — Animations dans AUJOURD'HUI

La carte **AUJOURD'HUI AU CAMPING** affiche maintenant :

- les informations fixes : piscine, restaurant, épicerie, etc.
- juste en dessous, **PROGRAMME D'ANIMATION DU JOUR**
- le programme est choisi automatiquement selon le jour actuel.

Exemple le dimanche :

🎉 PROGRAMME D'ANIMATION DU JOUR
20H00 • Pot d'accueil

Le bouton **Programme** continue d'afficher toute la semaine.

Pour modifier les animations, modifie uniquement `planning` dans `config.js`.
