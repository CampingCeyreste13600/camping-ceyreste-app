# 🎨 Couleurs du planning

Dans `config.js`, chaque animation peut maintenant être personnalisée.

Exemples :

```js
{ text: "10h00 • Aquagym", color: "blue" }
{ text: "21h00 • Soirée mousse", color: "pink", bold: true }
{ text: "⚠️ Réservation obligatoire", color: "red", bold: true, size: "small" }
{ text: "GRANDE SOIRÉE", color: "#ff7a00", bold: true, size: "large" }
```

Couleurs prédéfinies :
- green
- blue
- orange
- red
- purple
- pink
- teal
- yellow

Tu peux aussi utiliser une couleur HTML, par exemple `#ff69b4`.

Tu modifies uniquement `config.js`, puis tu valides la modification sur GitHub.
